# manda_coverage
ROS port of Damian Manda's MOOS based sonar coverage based path planner. https://github.com/mandad/moos-ivp-manda

Manda’s MS thesis can be found here:
Manda, Damian, "Development of Autonomous Surface Vessels for Hydrographic Survey Applications" (2016). Master's Theses and Capstones. 877.
https://scholars.unh.edu/thesis/877
